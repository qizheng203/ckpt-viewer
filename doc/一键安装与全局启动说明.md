# Ckpt_viewer v2 一键安装与全局启动说明

## 1. 目标

安装脚本用于让用户在 Linux 和 Windows 上一键完成安装，并在任意新终端直接运行：

```bash
ckpt-viewer
```

脚本不要求管理员权限。它会创建项目本地 `.venv`，安装运行依赖，生成用户级启动器，并更新用户级 PATH。

## 2. Linux / macOS

```bash
bash install.sh
```

脚本会执行：

1. 查找 Python >= 3.10。
2. 创建或复用 `.venv`。
3. 执行 `pip install -e .`。
4. 创建 `~/.local/bin/ckpt-viewer` 和 `~/.local/bin/pth-inspector`。
5. 将 `~/.local/bin` 写入用户 shell 配置。
6. 验证 `ckpt-viewer --version`。

安装完成后：

```bash
ckpt-viewer
ckpt-viewer analyze /path/to/model.pth --out report
```

如果当前终端仍找不到命令：

```bash
export PATH="$HOME/.local/bin:$PATH"
```

## 3. Windows

PowerShell：

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1
```

CMD：

```bat
install.bat
```

脚本会执行：

1. 查找 `py`、`python` 或 `python3`。
2. 检查 Python >= 3.10。
3. 创建或复用 `.venv`。
4. 执行 `pip install -e .`。
5. 创建 `%USERPROFILE%\.local\bin\ckpt-viewer.cmd` 和兼容入口。
6. 将 `%USERPROFILE%\.local\bin` 加入用户级 PATH。
7. 验证 `ckpt-viewer --version`。

安装完成后，重新打开 PowerShell、CMD 或 Windows Terminal：

```powershell
ckpt-viewer
ckpt-viewer analyze C:\path\to\model.pth --out report
```

## 4. 可选配置

```text
CKPT_VIEWER_PYTHON
CKPT_VIEWER_VENV
CKPT_VIEWER_BIN_DIR
CKPT_VIEWER_VENV_SYSTEM_SITE
```

示例：

```bash
CKPT_VIEWER_PYTHON=/usr/bin/python3.11 bash install.sh
CKPT_VIEWER_VENV_SYSTEM_SITE=0 bash install.sh
```

默认会启用 `--system-site-packages` 创建虚拟环境，便于复用用户已有 Python / conda 环境中的 PyTorch。若需要完全隔离环境，设置：

```bash
CKPT_VIEWER_VENV_SYSTEM_SITE=0 bash install.sh
```

## 5. 常见问题

### Windows 安装后当前终端找不到 ckpt-viewer

关闭当前终端，重新打开。用户级 PATH 更新不会影响已经打开的终端。

### Linux 新终端仍找不到 ckpt-viewer

确认 `~/.local/bin` 是否在 PATH 中：

```bash
echo $PATH
```

临时修复：

```bash
export PATH="$HOME/.local/bin:$PATH"
```

### Python 版本过低

安装 Python 3.10 或更高版本，然后重新运行安装脚本。
